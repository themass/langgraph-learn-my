## 🎨 新增的日志符号和含义

| 符号 | 含义 | 使用场景 |
|------|------|----------|
| `📥` | 节点输入 | 显示节点接收的输入数据 |
| `⚙️` | 配置信息 | 显示LLM配置、最大循环次数等 |
| `💭` | 思考过程 | 显示 LLM 的推理过程 |
| `⚡` | 决策 | 显示决定的动作和输入 |
| `🔧` | 工具调用 | 显示工具名称和参数 |
| `📊` | 观察结果 | 显示工具返回的结果 |
| `📋` | 生成的计划 | 显示研究计划详情 |
| `✅` | 成功/完成 | 任务完成或成功执行 |
| `❌` | 错误/失败 | 执行失败或错误 |

## 🔍 日志层级详解

### Level 1: 节点级别
- 节点开始 (`▶ 节点开始`)
- 节点结束 (`✅ 节点完成`)
- 执行时间统计

### Level 2: 配置级别
- LLM 配置信息
- 节点输入信息
- 节点输出信息
- 最大循环次数等常量

### Level 3: 执行级别（ReAct 循环）
- 推理循环边界
- 思考过程
- 决策信息
- 工具调用详情
- 观察结果

### Level 4: 总结级别
- 执行总结（循环次数、工具调用统计、证据收集）
- 步骤完成状态

## 🚀 使用建议

### 1. 调试时重点关注的日志

**查看推理过程**:
- 搜索 `💭 【思考过程】` 了解 LLM 的推理逻辑
- 搜索 `⚡ 【决策】` 查看决策结果

**查看工具调用**:
- 搜索 `🔧 【工具调用】` 查看调用的工具和参数
- 搜索 `📊 【观察结果】` 查看工具返回的结果

**查看执行统计**:
- 搜索 `📊 【执行总结】` 查看循环次数、工具调用统计

**查看节点输入输出**:
- 搜索 `📥 【节点输入】` 查看节点接收的数据
- 搜索 `📤 节点输出` 查看节点返回的数据

### 2. 性能分析

- 查看 `✅ 节点完成: XXX (X.XXs)` 了解每个节点的执行时间
- 查看 `推理循环次数` 了解是否有过多的无效循环
- 查看 `工具调用次数` 和 `成功/失败` 比例

### 3. 质量检查

- 查看 `💭 【思考过程】` 确保推理逻辑合理
- 查看 `📋 【生成的研究计划】` 确保计划步骤清晰
- 查看 `规划理由` 确保计划合理性
