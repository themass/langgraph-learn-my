## 🎯 核心设计

### 1. 节点结构（7节点）

```
1. task_analysis_node (任务分析)
   - 理解任务需求和复杂度
   - 识别领域和关键实体
   
2. knowledge_preparation_node (知识准备)
   - RAG 检索领域知识
   - 评估知识充分性
   
3. think_node (思考) ←─────────┐
   - 分析当前状态            │
   - 决定下一步行动          │
                             │
4. act_node (行动)            │
   - 执行工具调用            │
   - 错误处理               │
                             │
5. observe_reflect_node (观察与反思)
   - 评估行动效果            │
   - 调整策略 ──────────────┘
   
6. answer_generation_node (答案生成)
   - 生成最终答案和方案
   
7. quality_assessment_node (质量评估)
   - 评估答案质量
   - 决定是否重试
```

### 2. Think-Act-Observe 循环

```
think → act → observe_reflect → (条件判断)
  ↑                                    |
  └────────────────────────────────────┘
```

**循环控制：**
- 最大迭代次数：10 轮
- 置信度提前终止：≥ 0.95
- 反思结果：根据 `should_continue` 决定
- 手动终止：action == "finish"

```python
# 严格（高质量）

```

#### 质量评分阈值
```python
# 宽松
quality_threshold = 5.0

# 标准
quality_threshold = 6.0  # 默认

# 严格
quality_threshold = 7.0
```

### 2. **工具扩展**

添加新工具的步骤：

1. **定义工具函数**
```python
def new_tool(param: str) -> str:
    """新工具的实现"""
    return f"Result: {param}"
```

2. **注册工具**
```python
AVAILABLE_TOOLS["new_tool"] = Tool(
    "new_tool",
    "工具描述",
    lambda p: new_tool(p)
)
```

3. **更新 Prompt**
- 在 `format_think_prompt` 中会自动包含新工具
- 可选：在任务分析时推荐新工具

### 3. **知识库扩展**

添加新领域知识：

```python
KNOWLEDGE_BASE["新领域"] = [
    {
        "id": "domain-001",
        "topic": "主题",
        "content": "详细内容..."
    }
]
```
