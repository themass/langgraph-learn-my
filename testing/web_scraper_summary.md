# 网页内容获取工具总结

## 实现的功能

我为您实现了两个版本的网页内容获取工具：

### 1. 基础版本 (`test.py`)
- **功能特点**：
  - 支持多种请求策略
  - 自动重试机制
  - 完整的HTML解析
  - 内容保存到文件
  - 错误处理和日志输出

- **主要功能**：
  - 获取网页标题、描述、文本内容
  - 提取所有链接和图片
  - 支持多种编码格式
  - 自动处理相对链接
  - 保存结果到文本文件

### 2. 高级版本 (`advanced_web_scraper.py`)
- **功能特点**：
  - 多种反反爬虫策略
  - 模拟人类行为（随机延迟）
  - 多种User-Agent轮换
  - Cookie和Referer处理
  - JSON格式保存

- **反爬虫策略**：
  1. 多种User-Agent轮换
  2. 带Referer请求
  3. 先获取Cookie再请求
  4. Session保持
  5. 随机延迟模拟人类行为

## 遇到的问题和解决方案

### 问题1：403 Forbidden错误
- **原因**：目标网站有反爬虫保护
- **尝试的解决方案**：
  - 更换User-Agent
  - 添加Referer
  - 使用Cookie
  - 模拟人类行为
- **结果**：所有策略都失败，说明网站保护非常严格

### 问题2：编码问题
- **解决方案**：自动检测编码，支持多种编码格式

### 问题3：相对链接处理
- **解决方案**：使用`urllib.parse.urljoin`自动转换

## 使用建议

### 对于有反爬虫保护的网站
1. **检查robots.txt**：查看网站是否允许爬取
2. **使用代理**：考虑使用代理服务器
3. **降低频率**：增加请求间隔时间
4. **使用Selenium**：对于JavaScript渲染的页面
5. **联系网站管理员**：申请API接口

### 对于一般网站
1. **遵守robots.txt**：尊重网站的爬虫规则
2. **控制频率**：避免对服务器造成压力
3. **处理错误**：做好异常处理
4. **保存数据**：及时保存获取的数据
